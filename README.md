# Cat Water Meter

A parchment-style interactive web story about Lala, a cat guardian of an ultrasonic water meter.

## Tech Stack
- HTML5
- CSS3
- Vanilla JavaScript
- Canvas-based text layout
- Transparent PNG sequence animation
- GitHub Pages

## Files
- `index.html`: primary entry page
- `water-guardian-cat.html`: story page entry
- `groom_v2_transparent/`: transparent cat animation frames

## Notes
- The page uses relative asset paths so it can run on GitHub Pages.
- Rive runtime is wired as a future-ready fallback path.
