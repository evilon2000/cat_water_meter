# Cat Water Meter

A parchment-style interactive web story about Lala, a cat guardian of an ultrasonic water meter, presented as a GitHub Pages static site.

## Tech Stack
- HTML5
- CSS3
- Vanilla JavaScript
- Canvas-based text layout and measurement
- Transparent PNG sequence animation
- Responsive static asset delivery
- GitHub Pages

## Project Structure
- `index.html`: primary published entry page
- `water-guardian-cat.html`: duplicate story entry for direct linking
- `groom_v2_transparent/`: transparent cat animation frames
- `favicon.svg`: site icon

## Deployment
This project is intended to be published through GitHub Pages from the root of the `main` branch.

Recommended GitHub Pages configuration:
- Source: `Deploy from a branch`
- Branch: `main`
- Folder: `/ (root)`

## Notes
- The page uses only relative asset paths so it can run correctly on GitHub Pages.
- The current cat actor is driven by transparent PNG sequence frames.
- A future Rive upgrade path is possible, but this published version does not require Rive.
